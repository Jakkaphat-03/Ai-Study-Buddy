# AI Study Buddy - Project Constitution

## Project Overview

AI Study Buddy is an AI-powered document learning web application for university students.

Users can upload learning materials and use AI to help understand the content.

This project is built as a production-style SaaS application.

---

# Goal

Build a clean, scalable and maintainable web application.

The application should look like a real startup product instead of a university CRUD project.

---

# Tech Stack

Frontend

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

Backend

- Next.js Route Handlers

Database

- Supabase PostgreSQL

Authentication

- Supabase Auth

Storage

- Supabase Storage

AI

- Google Gemini API

Deployment

- Vercel

# Coding Rules

Always use TypeScript.

Always use Tailwind CSS.

Always use reusable components.

Keep components small.

Never duplicate business logic.

Use Server Components whenever possible.

Keep folder structure clean.

Never modify unrelated files.

Never install unnecessary packages.

Always write production-quality code.
